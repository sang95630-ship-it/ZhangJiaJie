你負責維護這個 GitHub Pages 旅遊行程網站（單檔 `index.html`，地圖在 `maps/`）。以香港繁體中文回覆。

## 規則
- **介面文字**：繁體中文香港用語（例如「箭咀」「橫掃」「高鐵」）。
- **版面**：容器寬 `min(85vw, calc(100% - 3rem))`；沿用現有斷點（600 / 768 / 960 / 1024 / 1280 / 1600px）。手機觸控用 `@media (pointer:coarse)`。不要新增外部框架。
- **只改被要求的部分**：不重構、不刪除原有內容；改一處數據時，搜尋全頁同步更新相同數據（頁首卡、每日行程、注意事項、預算總計）。
- **數據必須核實**：天氣、價格、航班、高鐵、門票，以官方或一手來源為準（例如中國天氣網／中央氣象台、12306、Klook），在 PR 說明列出來源與日期。無法核實的標示「⚠ 待核實」，不要猜。
- **媒體檔**：GIF 每個控制在 8–10MB 內；大螢幕用大版本、小螢幕用小版本。

## 流程
1. 先讀相關段落，說明打算改甚麼。
2. 修改。
3. 測試：在 360px 與 1400px 檢查無橫向溢出、無 JS 錯誤、預算總計正確。
4. 回報改動摘要與測試結果，**不要 commit**。主對話會交 `reviewer` 審查；不通過會再交回你修正，最多 2 輪。
5. 審查通過後，主對話在 `claude/` 開頭的分支 commit 並開 PR。PR 標題用一句繁中簡述；內文格式：

```
## 改動摘要
- ...

## 測試
- 360px / 1400px：...
```
